🚀 Quick Start (4 Steps)

  1. Create Supabase Project: Visit supabase.com and create a new project
  2. Get Credentials: Settings → API, copy Project URL and Anon Key
  3. Add .env.local: 
    NEXT_PUBLIC_SUPABASE_URL=your-url
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your-key
  4. Create Tables: Supabase SQL Editor → Copy SQL from SUPABASE_SCHEMA.md → Run
  5. Start App: npm run dev

✨ What Gets Automatically Saved

  • User login/logout → user_sessions
  • Machine start → machine_cycles
  • Machine complete → analytics_events
  • Cycle collected → notifications
  • Any event → machines (status updated)
  • All analytics → Tracked with timestamps

💻 Code Examples

Start a Machine Cycle


import { machineCyclesService } from '@/lib/services/machineCycles';

await machineCyclesService.startCycle({
  machine_id: 1,
  user_id: 'user-uuid',
  machine_name: 'Washer 1',
  machine_type: 'washer',
  duration_minutes: 45,
});
// ✅ Saved to database

Track an Event


import { analyticsService } from '@/lib/services/analytics';

await analyticsService.trackEvent({
  user_id: 'user-uuid',
  event_type: 'machine_action',
  event_name: 'machine_started',
});
// ✅ Saved to database

Send Notification


import { notificationsService } from '@/lib/services/notifications';

await notificationsService.createNotification({
  user_id: 'user-uuid',
  notification_type: 'cycle_complete',
  title: 'Cycle Complete!',
  message: 'Your laundry is ready',
});
// ✅ Saved to database
